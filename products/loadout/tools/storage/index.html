Assumptions

  • GB = Mbps x 60 x minutes / 8 / 1000, with 1 TB = 1000 GB.
  • Bitrate is treated as constant. Many cameras vary it with the scene, and audio and metadata add a little.
  • Cards count 93% of the stated size as usable, since formatting takes some. Leave extra room.
  • These are estimates. Presets are approximate. Check your camera's spec for the real figure.
