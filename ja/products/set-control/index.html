ワークフロー

  1. 作成撮影日、チーム、ロケ地
  2. 送信1回の更新をすべてのスマートフォンへ
  3. 確認誰が受け取ったかを確認
  4. 進行当日をリアルタイムで追跡

課題

状況は常に変わります。書類は古くなり、スケジュールはずれ、ロケ地が移り、時間が調整される。誰かが声に出して聞くまで、それが必要な人に届くことはありません。

解決策

スケジュール、ロケ地、ショットの進み具合、時間、制作状況を、ひとつの共有ビューで管理します。一度行った変更は、iPhone の通知で全員に届きます。プリプロダクションと撮影中の非効率なやりとりをなくします。

01 · スケジュール

シーンを移動すれば、関係者全員に伝わる。

撮影日の間でシーンをドラッグ。Set Control は誰がいつ働くかを把握し、移動した日ごとに通知します。

02 · キャストと送迎

すべての俳優、すべての送迎、すべてのファイル。

各俳優のピックアップ、ヘアメイク、衣装、現場入りの時間。ドライバーと同乗者には、それぞれの送迎だけが表示されます。台本の抜粋、許可証、配置図は、必要な人に届きます。

03 · ロケ地で

どこに停めて、どこへ行くか。

駐車場マップ、最寄りの病院、すべてのピックアップと送り届けを、コールシートにそのまま掲載。

04 · 当日の進行

15分押し。全員が把握。

シーンが回り始めたら開始をタップ。Set Control が前倒しか遅れかを計算し、すべてのスマートフォンに反映します。

05 · 撮影終了

その一日を、記録に。

その日の内容から制作レポートが自動で作成されます。ファーストショット、撮影終了、各シーンとスケジュールの比較、コールシートを確認した人。

  • 05

    ピックアップ、ヘアメイク、衣装、現場入り。俳優には自分の情報が最初に表示されます。

    ピックアップと駐車場

    ドライバーごとの送迎と、ロケ地ごとの駐車場マップ。

  • 08

    撮影日ごとのファイル

    台本の抜粋、絵コンテ、許可証、地図を、全員または部署ごとに。
