    The order that works.

    • Upload the clips first. Every site matches a row to a clip by its file name, so the files have to be there before the sheet.
    • Keep file names identical. Same spelling, same extension. A renamed file won't pick up its row.
    • Then add the sheet. Upload CSV on Adobe Stock, the CSV button on Shutterstock's Submit page, Apply CSV on Pond5.
    • Check the categories. The converter picks them from your keywords. A quick look before you submit is worth it.

    To check titles and keywords one clip at a time first, use the free title and keyword checker. For the files themselves, the clip spec checker shows what each site would refuse.

    Writing the sheet in the first place.

    Converting a sheet takes seconds. Writing one, a title, a description and 20 to 40 keywords per clip, is where the evenings go. At about 2 minutes a clip for the prep alone, 500 clips is 16+ hours before any keywording.
