Why the same file looks different.

A video file stores numbers, plus a small tag that tells players how to turn those numbers into brightness on screen. Editors and players don't all read that tag the same way.

Adobe explains the most common case: Premiere Pro follows the TV standard, a 2.4 gamma, while macOS shows Rec. 709 video with a 1.96 gamma. So a file tagged Rec. 709 looks lighter and flatter in QuickTime Player and Safari on a Mac than it did in your editor. Nothing went wrong in the export. The two screens are following different rules.

The fix is to decide where most people will watch, and set your editor so what you see while grading matches that screen.

Reading the tags.

  • Color (primaries). Which set of reds, greens and blues the numbers mean. Rec. 709 for normal HD video, Rec. 2020 or P3 for wide color.
  • Curve (transfer). How numbers turn into brightness. Rec. 709 for normal video, PQ or HLG for HDR. This is the one behind most washed-out exports.
  • Matrix. How the color numbers were packed. It should match the color, Rec. 709 with Rec. 709.
  • Range. Video range is normal for video files. A file marked full range can look crushed or grey in players that expect video range.
  • No tag. Every player guesses, so the file looks different everywhere. Export with the color space set and the tag gets written.
